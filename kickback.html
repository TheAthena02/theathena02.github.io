Development
Kickback uses a custom procedurally generated level built from the ground up. It uses modules that are randomly picked and spawned in a line from the start block, with checkpoints that clear previous levels.

This blueprint handles the base spawning of modules. The spawn handler creates itself and calls the function over again, until it reaches the max amount of spawns. It then creates a checkpoint. This checkpoint clears all previous modules and starts the cycle again anew.


Each Weapon has similar functions, but applies a different force to the player and damage to the enemy.

Here, I use structures to keep track of the current weapon data. This is then used to update the HUD. Each reload has a timer. I found that it was more enjoyable to have the guns reload, even when not equiped, to keep the gameplay moving quick.
